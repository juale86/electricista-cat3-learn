# Catálogo de imágenes de uso libre – Instalaciones eléctricas domiciliarias

Todas las imágenes son de **Wikimedia Commons**; la licencia y el autor se verificaron con la API de Commons (metadatos de la página del archivo: `LicenseShortName`, `Artist`). Las notas de calidad salen de la descripción, la resolución y el título de cada archivo, no de mirar la foto: antes de publicar, abrí cada página y revisala a ojo (fondo, marcas visibles, encuadre).

**Recordá:** las CC BY-SA obligan a atribuir y, si modificás la imagen (recorte, retoque), a compartir la versión modificada con la misma licencia. Dominio público y CC0 no exigen atribución, pero se deja el texto por cortesía.
